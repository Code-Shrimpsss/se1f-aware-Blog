# Prototype C V2 — 意识形成 / 观象印痕

这是一个与正式站点、Prototype A/B/C 完全隔离的第一阶段高保真原型。它只实现：

1. **序幕：意识形成**——黑暗确定一个位置，四道空间切面留下非对称白色核心；裂缝先于外壳响应压力，悬浮切片最后移动，每次呼吸给几何留下微小差异。
2. **观象：信息留下视觉痕迹**——第一次推进把同一个核心连续放大为地貌；真实文章片段以不同运动规律经过，少数内容在表面形成切口、曝光、压力纹、沉积层与铭文；被用户持续观看的碎片使世界冻结，并制造不可逆的深裂缝。

本轮没有实现“构序 / 观心 / 见性”，也没有为它们创建占位 Section。最终深裂缝是未来第二阶段的合法入口，但此原型到观象余波即结束。

## 本地运行

在仓库根目录执行：

```bash
python3 -m http.server 4173
```

然后访问：

```text
http://127.0.0.1:4173/design-prototypes/prototype-c-v2-formation-imprint/
```

也可以直接通过 `file://` 打开 `index.html`；使用本地 HTTP 仅用于更稳定的浏览器验证。

## 输入

- **滚轮 / ArrowDown / PageDown / Space**：推进一次明确因果，不映射为普通页面滚动距离。
- **指针停留**：在核心上停留约 680ms，使局部停止呼吸并留下余痕；在信息碎片附近停留约 760ms，使该碎片获得不同运动规则。
- **上滑 / 长按**：移动端分别对应推进和持续观看。
- **ArrowUp / PageUp**：在观象余波中回到已经改变的核心。
- **Esc**：随时唤出稳定的现实锚点；文章索引与阅读器不参与空间变形。
- **声音**：默认关闭；只有用户主动点击后才创建 Web Audio 上下文。全部声音均由浏览器本地合成，并有等价视觉事件。

如果用户在形成完成前推进，所有尚未发生的切面会在约一秒内压缩完成；核心不会被跳过或换成另一个模型。

## 世界规则

- 核心由切面留下，不由粒子聚合。
- 序幕核心与观象地貌共享同一条裂缝、同一份不可逆 revision 和同一个观察余痕。
- 呼吸不是整体缩放：压力根据各顶点到内部节点的距离传播，裂缝先收紧，外壳随后形变，悬浮切片最后移动。
- 内容类别不使用彩色标签或图标；其差异由物理后果表达。
- 风暴冻结时，所有碎片使用冻结瞬间的同一份位置，只有被观看的碎片使用独立时钟继续移动。
- 撞击后形成的深裂缝写入当前浏览器的 `localStorage`，返回核心或下次访问时不会被当作从未发生。

## 性能与降级

- DPR 上限：桌面 `1.75`，移动端 `1.35`；低内存或低核心数设备进一步降到 `1.2`。
- 移动端减少地貌网格与风暴碎片数量，但保留切面、呼吸传播、冻结、唯一碎片和深裂缝五个事件。
- 页面进入后台后停止 RAF 与 CSS 动画；恢复时从剩余的有效可见时间继续。
- `prefers-reduced-motion` 使用可逐步推进的静态状态，不运行摄影机高速穿越或持续呼吸时钟。
- Canvas 失败或 JavaScript 关闭时，语义化声明与普通内容入口仍然可读。
- 无 CDN、无外部请求、无分析脚本、无敏感数据。文章内容只读取本地 `../shared/content.js`。

## 浏览器验证状态

以下查询参数只用于本地、确定性的截图与 QA；它们不显示在正常体验中，也不发送请求：

```text
?shot=core
?shot=core-observed
?shot=surface
?shot=storm
?shot=fragment-observed
?shot=freeze
?shot=impact
?shot=observation
```

其中 `?shot=observation` 对应观象余波：不同材质印痕、最深裂缝与可被斜光找回的文章入口均已保留。

运行时可在浏览器控制台读取只读诊断：

```js
window.SelfAwakeV2.getState()
```

也可在本地验证时调用：

```js
window.SelfAwakeV2.jumpTo('storm')
window.SelfAwakeV2.selectFragment()
window.SelfAwakeV2.advance()
```

## 文件职责

- `index.html`：单一固定世界、空间文字、现实锚点、文章阅读层与无脚本回退。
- `styles.css`：黑白材质、空间深度层、观察坐标、移动端重构与可访问性样式。
- `world.js`：Canvas 伪 3D 核心、切面、传播式呼吸、摄影机推进、地貌、信息风暴和永久印痕。
- `script.js`：有限状态机、输入意图、停留因果、生命周期、声音、本地痕迹和文章安全层。
- `screenshots/`：桌面与移动端真实浏览器验证证据。
