# Self-Awake Möbius — 状态机、镜头与物质继承

## 节奏模型

15 个状态只是调试坐标，不是 15 张幻灯片。真实滚动由以下导演模式控制：

| 模式 | 用途 | 体感 |
|---|---|---|
| `opening` | 首页锁定与靠近 | 先读清整体，再逐渐进入 |
| `burst` | 观象信息经过 | 首个速度高潮 |
| `hold` | 节点吸收、观点生成、返照 | 自动减速并留白 |
| `cinematic` | 主题间穿梭 | 短暂镜头惯性 |
| `direct` | 构序归类 | 稳定跟手 |
| `align` | 跨时间关系 | 精准、缓慢 |
| `plunge` | 构序进入观心 | 短促失重 |
| `echo` | 观心时间层 | 整体降速 |
| `reveal` | 见性总体显现 | 短而可辨认 |
| `final` | 剥离与返照 | 缓慢退去、极慢结尾 |

快速滚动只更新目标状态，当前镜头仍按不同模式的追随速率抵达；反向滚动使用同一条连续相机链恢复，不执行瞬移。

## 相机链

- 首页：固定雕塑构图，轻微指针视差。
- 首页到观象：贝塞尔靠近，进入侧的法线在整段飞行中固定，避免内外翻面闪屏。
- 观象到构序：相机偏离中心；一侧曲面极近，另一侧保留开放黑暗。
- 构序：在曲面坐标上观察新节点与两个已有节点共同改变曲率，并在关系负空间里生成新观点。
- 构序到观心：穿过跨时间表面之间的折缝。
- 观心：同一个房间的多个时间状态在原位替换。
- 观心到见性：镜头先对准同一开口，再穿门而出，沿表面离开后才脱离骨架。
- 见性：第一次重新看见整体，随后实体退回路径与白点。

## 思想节点

`thoughtNodePathV` 定义一条浅 S 形参数路径，作为同一个思想节点在四层中的稳定身份：

1. 观象：信息发生接触、沉积并被表面吸收，成为一个被真正看见的节点。
2. 构序：新节点与两个已有知识表面采用同一曲率；它们之间形成新的负空间，观点从关系中生成。
3. 观心：节点成为判断界面，让系统看见经验、情境与矛盾如何参与判断。
4. 见性：生成的观点失去独立形体，沿莫比乌斯曲面传播并改变局部曲率、光路与呼吸节律。
5. 下一轮：本地状态保存已经完成的运行；首页的整体仍是原来的整体，但保留一处细微更新。

它不是伤口、知识标签或简单连线，而是一条完整的系统运行证据：接收、理解、关联、生成、扩展并融合。
