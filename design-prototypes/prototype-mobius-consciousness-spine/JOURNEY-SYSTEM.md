# Self-Awake Möbius — 状态机、镜头与物质继承

## 节奏模型

15 个状态只是调试坐标，不是 15 张幻灯片。真实滚动由以下导演模式控制：

| 模式 | 用途 | 体感 |
|---|---|---|
| `opening` | 首页锁定与靠近 | 先读清整体，再逐渐进入 |
| `burst` | 观象信息经过 | 首个速度高潮 |
| `hold` | 印痕、对齐、返照 | 自动减速并留白 |
| `cinematic` | 主题间穿梭 | 短暂镜头惯性 |
| `direct` | 构序归类 | 稳定跟手 |
| `align` | 跨时间关系 | 精准、缓慢 |
| `plunge` | 构序进入观心 | 短促失重 |
| `echo` | 观心时间层 | 整体降速 |
| `reveal` | 见性总体显现 | 短而可辨认 |
| `final` | 剥离与返照 | 缓慢退去、极慢结尾 |

快速滚动只更新目标状态，当前镜头仍按不同模式的追随速率抵达；反向滚动使用同一条连续相机链恢复，不执行瞬移。

## 相机链

- 首页：固定雕塑构图，轻微指针视差。
- 首页到观象：贝塞尔靠近，进入侧的法线在整段飞行中固定，避免内外翻面闪屏。
- 观象到构序：相机偏离中心；一侧曲面极近，另一侧保留开放黑暗。
- 构序：在曲面坐标上观察由印痕长出的承重面。
- 构序到观心：穿过跨时间表面之间的折缝。
- 观心：同一个房间的多个时间状态在原位替换。
- 观心到见性：镜头先对准同一开口，再穿门而出，沿表面离开后才脱离骨架。
- 见性：第一次重新看见整体，随后实体退回路径与白点。

## 原始印痕

`masterScarV` 定义一条浅 S 形参数路径，具有固定肩部和双暗纹特征：

1. 观象：外部信息被真正看见后进入材质。
2. 构序：同一参数区间成长为墙体和承重轴。
3. 观心：成为系统观察自身时的时间界面与房间开口。
4. 见性：重新出现在完整环上，随剥离退回光。
5. 下一轮：本地路径状态保留其已发生的证据，后续可用于再次访问的微弱形变。

这条印痕表示信息已经被系统转化，不代表创伤、裂口或等待修复的伤口。
