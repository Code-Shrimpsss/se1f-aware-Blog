# Möbius consciousness spine · SVG system

This system is derived from the actual WebGL prototype rather than from a generic infinity symbol.

## Core assets

- `logo-consciousness-spine.svg` — detailed bone-surface master mark
- `logo-consciousness-spine-mono.svg` — one-colour mark using `currentColor`
- `logo-consciousness-spine-small.svg` — reduced 64×64 open Möbius path for interface/favicon use
- `logo-lockup-horizontal.svg` — black-field horizontal lockup

## Stage sigils

- `sigil-observation-imprint.svg` — information becoming an irreversible scar
- `sigil-order-bearing.svg` — a scar growing into load-bearing order
- `sigil-reflection-time.svg` — offset time membranes turning toward the observer
- `sigil-nature-removal.svg` — added structures receding from the single surface

## Editorial/system assets

- `surface-scar-divider.svg` — low-emphasis editorial scar
- `consciousness-transformation.svg` — four transformations of one surface, not a four-node flowchart

## Visual contract

- Void: `#000000`
- Bone: `#eceae3`
- No brand accent colour
- Thickness and negative space are structural, not decorative
- Asymmetry, scars and attached constructions carry memory
- `见性` is represented by removal, never by adding a final emblem
- Monochrome assets inherit `currentColor`; structural scars are transparent mask cuts and therefore work on any surface
