# 当代个人写作与交互站点观察（2026-07-12）

这份研究只提取可执行原则，不复制任何站点的视觉资产、布局或交互。

## 观察来源

### Awwwards Portfolio Gallery

- 来源：<https://www.awwwards.com/websites/portfolio/>
- 类型：当前策展画廊。
- 首屏观察：画廊把筛选、数量与作品图像放在同一层级，大片留白让目录本身成为场景；但大量案例仍依赖缩略图网格，容易把个体差异压回模板化卡片。
- 对本项目的启示：保留“可发现的坐标与数量”，拒绝缩略图墙；文章标题和关系应该直接构成空间。

### Codrops

- 来源：<https://tympanus.net/codrops/>
- 类型：前端效果与交互出版物。
- 首屏观察：2026 年 7 月的内容强调轻量 WebGL 氛围、波传播、滚动相机路径与持续页面转场；首页仍让标题和文章入口承担导航，而不是让效果替代内容。
- 对本项目的启示：复杂体验可以由少量几何和一致的相机/状态语法完成；先确保每个空间动作都能映射到文章关系，再决定是否需要 WebGL。本轮三个原型分别优先使用 CSS 3D、SVG/Canvas 2D 与轻量 Canvas，而非统一堆入 Three.js。

### Josh W. Comeau

- 来源：<https://www.joshwcomeau.com/>
- 类型：技术写作型个人站。
- 首屏观察：环境插画形成鲜明记忆，但文章标题、摘要、分类和阅读动作仍是页面的骨架；装饰层与语义内容可以分离，脚本或图像失效不影响理解。
- 对本项目的启示：意识核心是入口氛围，文章索引必须是独立、真实的 HTML；阅读层不继承首页的视觉负担。

### Maggie Appleton

- 来源：<https://maggieappleton.com/>
- 类型：数字花园与视觉写作个人站。
- 首屏观察：一句明确的作者命题占据主要视野，随后按 Essays / Notes / Patterns / Library 等不同认知状态组织内容；时间与成熟度参与内容分类，而不是只按标签归档。
- 对本项目的启示：四层意识必须改变文章的上下文与成熟度，而不是给同一列表换标题；“原型内容”与“已发布内容”要诚实区分。

## 汇总原则

1. **让写作构成视觉对象。** 标题、时间、摘要、关系与阅读痕迹直接生成空间，不把它们装进通用卡片。
2. **只花一次野心。** 每个方向一套动作语法，其他反馈都退居辅助。
3. **语义先于渲染。** 视觉核心与文章 DOM 分层，静态 fallback 仍有完整秩序。
4. **时间是信息，不是装饰。** 跨年复现、更新与停留共同决定连接何时出现。
5. **移动端重写构图。** 保留概念和阅读路径，主动减少空间层级与持续动画。
6. **不从画廊复制答案。** 黑白材料、四层意识和返照问题来自 Self-Awake 自身命题。
