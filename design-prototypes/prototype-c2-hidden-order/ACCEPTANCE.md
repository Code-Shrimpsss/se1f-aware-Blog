# C2 — 隐序呼吸 / Hidden Order

## 锁定关系

- 视觉源：`C — 呼吸核心 — ../prototype-c-breathing-core/index.html`
- 保留源：`A — 切片核心 — ../prototype-a-sliced-core/index.html`
- 本目录是独立优化原型，不覆盖 A、B、C，也不进入生产站点。
- A 的初始切片形成动画被标记为 **reserved motif / 待安放语言**。本轮不强行植入 C2。

## 要解决的问题

C 的系统并不缺失；问题是可见解释比体验先到达。C2 必须把显式系统图从界面撤走，让访客通过行为与空间回应自行发现秩序。

## 可见减法门槛

### 首屏只允许

1. 一个骨白呼吸核心；
2. 一句意识声明；
3. 微小 `self-awake / self-awareness` 署名；
4. 一个“继续靠近”提示；
5. 一个低权重普通文章索引逃生入口。

首屏禁止出现 `00—04`、五层地图、D1—D4、呼吸读数、痕迹数量、停留说明、隐私段落、完整功能菜单或左右两套导航。

### 每个深入状态最多允许

- 一个层名，抵达后短暂显现约 1.2 秒，再退入黑暗；
- 一句不超过 24 个汉字的判断；
- 一个真实思想片段；
- 一个由当前行为产生的必要反馈。

不得用正文解释动画已经表达的含义。

## 连续舞台门槛

- 视觉上始终是同一个固定核心与同一片空间。
- 滚动轨可以保留语义区段与原生高度，但不能被看成五个普通满屏章节。
- 场景变化只改变核心的膜片数量、呼吸、材质、折叠邻接、可见文字和余光。
- 一次滚轮意图最多改变一个内部状态。
- 到见性时，核心、层级、进度、菜单和技术标签真正消失。

## 唯一 signature moment

状态必须形成清晰因果链：

1. 访客 hover 或 focus 一个真实思想片段；
2. 对应局部膜片停止呼吸；
3. 持续 2.4 秒后，远端不同年份的区域采用完全相同的节律；
4. 不出现连线；
5. 整个空间沿不可见维度折叠，让两个遥远表面成为邻接面；
6. 两侧分别只出现半句话，合并后构成完整判断；
7. 中间裂缝此时才成为可发现、可聚焦、可点击的入口；
8. 点击后产生穿缝过渡，并打开真实语义化 `dialog > article`；
9. 阅读后退出，空间保留极弱本地余痕，但不展示统计面板。

默认事件内容使用共享关系：

- 2022：《当效率不再回答我》
- 2026：《未被命名之前》
- 两侧半句：`推进并不等于` / `抵达。`

## 访问性与降级

- 普通索引、搜索、关于放在同一个边缘入口内，不使用第二套常驻菜单。
- 思想片段、裂缝、文章、关闭、返回均可通过键盘完成。
- Canvas 失败时保留静态骨白核心、当前判断、普通索引和正文入口。
- `prefers-reduced-motion` 下不循环呼吸、不做穿越镜头；用户仍需主动 hover/focus 2.4 秒，之后直接呈现静态邻接、半句和裂缝。
- 页面隐藏时暂停 Canvas、CSS 动画和剩余停留计时，恢复后继续。
- DPR：桌面 ≤ 1.75，移动 ≤ 1.35。
- 390×844 重新组织为上半屏核心、下半屏当前片段；不显示桌面地图。

## 通过标准

1. 不读说明，访客能否察觉“我的停留使空间发生了回应”？
2. 移除所有解释文案后，四次深入是否仍能从密度、节律和消失中被感知？
3. 是否存在且只存在一个只能属于 Self-Awake 的记忆事件？
4. 1440×900 与 390×844 是否无横向溢出、文字裁切和功能遮挡？
5. 搜索、普通索引、文章正文、键盘、降动效与 Canvas fallback 是否仍然完整？
