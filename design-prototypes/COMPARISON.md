# 三个方向的核心判断

## A — 切片核心

**一句判断：** 三版中最像“可以被逐层剖开的未知意识建筑”，也是第一眼最有纪念碑感的方向。

### 优点

- 白色切片本体最严密，黑白材料关系最接近原始命题。
- 首屏的空间尺度、裂缝与“未闭合”叙事无需解释就能成立。
- 四层滚动变化最容易理解：外表面 → 错位通道 → 时间切面对齐 → 结构退场。
- 文章自然成为切面铭文、门和缝，不像漂浮卡片或知识图谱。
- 桌面与移动都保留强识别度。

### 风险

- 如果正式迁移时加快或放大错位，容易被误读为常见的产品爆炸解构。
- 多层 CSS 几何需要谨慎控制合成与旧浏览器 fallback。
- 它最“建筑”，因此持续生成和人的温度需要依靠阅读痕迹来补足。

## B — 折叠核心

**一句判断：** 三版中最准确地把“第四维”变成关系与观察顺序，而不是模型复杂度。

### 优点

- 构序场景最强：不是增加连线，而是交换什么与什么相邻。
- 内外、过去/现在与远近的翻转让有限内容呈现不同结构，概念上最接近四维命题。
- 无 Canvas/WebGL，性能成本最低，静态 fallback 与语义 DOM 最稳。
- 文章与关系可以通过折面共享边界，内容机制有很强的可扩展性。
- 移动端横向折面是重新构图，不是桌面缩小。

### 风险

- 首屏比 A 更需要观看，访客可能先把它理解为抽象纸雕或折纸。
- 关系变化必须与真实文章元数据严格绑定，否则很容易沦为任意翻转。
- 如果加入过多折面，会从“不可思议的邻接”滑向视觉噪声。

## C — 呼吸核心

**一句判断：** 三版中最能让意识被感为“持续形成且会记得认真停留的存在”。

### 优点

- 呼吸、同步和残留是一套统一动作语言，内部温度最自然。
- “爱”通过相隔年份采用同一节律显现，没有使用暖色滤镜或煽情文案。
- Canvas 2D 足以形成独特本体，DPR、几何量、页面隐藏与移动功耗都可控。
- 阅读痕迹进入本体内部，而不是只出现在导航或统计面板。
- 最深处退化成无法完全打开的节点，返照场景最安静。

### 风险

- 生命感依赖运动，静态首屏的建筑尺度与压迫感不如 A。
- 膜片密度或亮度稍有失衡，就可能像器官、百叶、肋骨或发光笼。
- 正式版需要用真实阅读停留而不是简单计时，避免“等待 2.4 秒”成为可预测机关。

## 可以融合的部分

如果后续选择融合，最有价值的组合不是把三个模型叠在一起，而是只保留一套主形体，并借用另外两版的内容机制：

- **从 A 继承：** 黑暗中的骨白物质感、未闭合裂缝、空间尺度与清晰剖层。
- **从 B 继承：** 文章关系通过邻接变化显现、过去与现在重叠、观察顺序影响上下文。
- **从 C 继承：** 停留同步、本地阅读余痕、页面对认真阅读的克制记忆、最深处的微弱节点。
- **共同保留：** 边缘导航、普通文章索引、可靠搜索、语义正文、移动重构与降动效。

### 融合时必须删除的东西

- 不能同时出现“切片错位 + 折面翻转 + 膜片呼吸”三套主动画。
- 不能在 A 的建筑外再包一层 C 的有机膜，也不能让 B 的折面从 A 的切片中任意飞出。
- 不能为了展示三版成果而保留三个核心对象。

一个可控的融合方式是：选择 A 作为唯一形体，B 负责文章关系如何改变切片邻接，C 只负责停留后的同步光痕与本地记忆。另一种是选择 C 作为唯一形体，借 B 的关系交换决定哪些区域同步，而不引入 A 的建筑切片。

## 当前建议

如果优先追求“第一眼进入一座意识建筑”，推荐 **A — 切片核心**。  
如果优先追求“第四维真正发生在关系与观察顺序中”，推荐 **B — 折叠核心**。  
如果优先追求“持续生成、停留和跨时间连接的内部温度”，推荐 **C — 呼吸核心**。

本轮不替用户选择，也不制作融合原型。下一步需要明确锁定：`方向字母 — 语义名称 — 精确文件路径`；如果选择多个部分，再先列出继承、删除与统一规则，然后另建融合原型。正式站点仍然不能迁移。
