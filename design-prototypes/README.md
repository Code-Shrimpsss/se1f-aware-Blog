# Self-Awake 四维意识空间原型

本目录是正式站点之外的视觉验证区。三个方向共享内容与设计命题，但拥有完全独立的空间结构、样式和交互实现。获得明确视觉确认之前，不会迁移到 `app/`、`components/` 或生产 CSS。

## 本地运行

在仓库根目录执行：

```bash
python3 -m http.server 4173
```

然后访问：

- 对比入口：<http://localhost:4173/design-prototypes/>
- A — 切片核心：<http://localhost:4173/design-prototypes/prototype-a-sliced-core/>
- B — 折叠核心：<http://localhost:4173/design-prototypes/prototype-b-folded-core/>
- C — 呼吸核心：<http://localhost:4173/design-prototypes/prototype-c-breathing-core/>

## 目录

```text
design-prototypes/
  SPEC.md                         共享执行规格
  RESEARCH.md                     当代站点观察与提取原则
  COMPARISON.md                   三方向优点、风险与可融合部分
  QA.md                           自动检查、浏览器验证与截图证据
  shared/content.js               三版统一内容、主题与关系
  prototype-a-sliced-core/        A：隐藏轴切片建筑
  prototype-b-folded-core/        B：不可能邻接折叠空间
  prototype-c-breathing-core/     C：持续生成的呼吸结构
  screenshots/                    统一视口验证截图
```

原型文本中凡标记“原型内容 · 待作者确认”的文章，均仅用于验证完整内容秩序，不伪装成作者的真实经历或观点。
