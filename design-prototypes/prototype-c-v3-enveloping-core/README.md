# Prototype C V3 — 包覆核心校正版

这是一次只针对视觉语言的快速迭代。它保留 V2 的形成、呼吸、滚动状态机、信息风暴、冻结、撞击和本地后果，但删除了三类被否决的隐喻：

- 中央消失点、地平线和纵向网格形成的“道路”；
- 十字、圆环和坐标轴形成的“射击准星”；
- `SOUND / OFF / ESC`、阶段编号和教程文案形成的“游戏 HUD”。

本目录与 V2、Prototype A/B/C 和正式站点完全隔离。详细视觉验收条件见 `ACCEPTANCE.md`。

## 本地运行

在仓库根目录执行：

```bash
python3 -m http.server 4173
```

访问：

```text
http://127.0.0.1:4173/design-prototypes/prototype-c-v3-enveloping-core/
```

## 本轮视觉变化

### 形成

- 黑暗只保留压力凹陷与一个确定位置，不绘制同心环。
- 形成由两次宽切面完成，不再左右交替补充大量碎片。
- 核心改为“重主体 + 外轮廓缺口 + 右上悬臂 + 深空腔 + 非中央裂隙”的非对称单体。
- 三个附属结构具有明显尺度和厚度差异，并使用哑光建筑材质。

### 靠近

- 声明在 Canvas 后方保持存在，由扩张的白色实体真实遮挡。
- 核心先越过画幅边缘；包覆曲面随后从同一裂缝坐标向四个方向展开。
- 不再把核心与独立地貌交叉淡化。

### 观象

- 删除全部 horizon、perspective spread、远景立柱和中央消失点。
- 满屏曲面以 UV 网格进行非透视弯曲，无法判断是墙、地面还是外壳。
- 序幕与观象使用同一个 `CRACK_PROFILE`。
- 信息从八种方向和多个深度经过，而不是沿一条纵向路径前进。
- 印痕、沉积、纹理、文章铭文和撞击目标全部通过曲面采样定位。

### 光标与界面

- 沉浸画面只保留一个 5px、低对比的柔和点。
- 靠近核心或显影区域时，点会消失，反馈转移到表面凹陷与光线偏折。
- 按钮和正文恢复普通指针反馈。
- 声音与菜单改为安静中文文字入口；无方框、快捷键徽标或控制台排版。
- 所有可见教程文案退出画面，但 `aria-live` 语义反馈仍保留。

## 四个视觉验收状态

以下参数只设置本地确定性状态，不请求网络：

```text
?shot=formation
?shot=approach
?shot=observation
?shot=reveal
```

分别对应：切面形成、核心越框、无方向观象、材质显影。

## 输入与降级

- 滚轮、方向键、PageDown、Space、Enter：推进一次明确状态。
- 指针停留：使核心或信息局部改变物理规则。
- 移动端上滑与长按：对应推进与持续观察。
- Esc：打开稳定文章安全层。
- 声音默认关闭，仅在用户主动开启后使用本地 Web Audio。
- `prefers-reduced-motion` 使用逐步静态状态，不运行高速穿越或持续呼吸。
- Canvas 或 JavaScript 失败时保留语义化声明、文章入口和 CSS 核心。

window.SelfAwakeV3.getState()
window.SelfAwakeV3.jumpTo('storm')
window.SelfAwakeV3.selectFragment()
