# C / V3 定向视觉校正

本轮只校正视觉隐喻，不增加“构序、观心、见性”，也不迁移正式首页。

## 全局反模式

- 不存在天空与地面的分界线。
- 不存在中央消失点、道路、轨道、走廊、桥梁或唯一前进方向。
- 不存在十字、圆环、锁定框、扫描线或任何准星符号。
- 不存在 `SOUND / OFF / ESC` 式游戏 HUD、方框状态键或阶段编号。
- 不存在飞行卡片、教程文案、沿路径排列的文章入口。
- 不使用整体缩放循环模拟呼吸。

## 四张必须成立的构图

### 1. Formation

- 至少 80% 纯黑空间。
- 一道宽切面与它已经留下的实体同时存在。
- 核心是可记忆的非对称白色单体：重主体、右上悬臂、外轮廓缺口、负空间和未闭裂缝。
- 不出现署名、菜单、声音、进入提示、完整声明或章节名。

### 2. Approach

- 与 Formation 完全相同的核心和裂缝。
- 核心从多个方向越过画幅，白色结构向四周包覆用户。
- 没有地平线，没有脚下平面，没有场景交叉淡化。
- 声明仍存在于空间中，但被实体真实遮挡。

### 3. Observation

- 视口是一块无法判断方向的巨大白色外壳近景。
- 同一裂缝从一个非对称边缘进入、从另一个边缘离开；不能自上而下形成路线。
- 信息从至少四种方向和多个深度经过。
- 技术切口、曝光残留、压力纹和沉积铭文都贴合曲面。
- 没有远景立柱、棋盘地面、固定阶段 UI 或解释文案。

### 4. Reveal

- 表面因停留产生局部凹陷、斜光偏折和深层纹理。
- 文章标题像压入材料的铭文，不是 DOM 卡片或物品提示。
- 深裂缝与撞击后果仍然存在。
- 光标在表面附近隐去，画面中没有准星或选中框。

## 工程边界

- 保留 V2 的状态机、冻结、唯一碎片、撞击、本地后果、文章安全层和默认静音。
- 原 V2、Prototype A/B/C、共享内容、正式站点与设计文档保持不变。
- Canvas 失败、JavaScript 失败和 `prefers-reduced-motion` 仍有可读、可推进的等价状态。
